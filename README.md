# 📚 Library Management System

## 1. Project Overview

The Library Management System is a full-stack web application developed to manage library books efficiently.

The system allows users to add, view, update, and delete book records. It also provides search functionality, input validation, and REST API integration.

This project is developed as part of the Complete CRUD-Based Web Application Development activity.

---

## 2. Problem Statement

Managing library book records manually can be time-consuming and may lead to errors or duplicate records.

The Library Management System provides a simple digital solution for maintaining book information and performing CRUD operations efficiently.

---

## 3. Objectives

The main objectives of this project are:

- To develop a user-friendly library management application.
- To implement Create, Read, Update, and Delete (CRUD) operations.
- To store book information in a database.
- To provide REST API endpoints for book management.
- To implement client-side and server-side validation.
- To provide search functionality.
- To demonstrate frontend-backend integration.
- To test API endpoints and application functionality.
- To maintain the project using Git and GitHub.

---

## 4. Features

### Book Management

- Add new books
- View all books
- Edit existing books
- Delete books
- Search books
- Filter books by information
- Display book availability status

### Validation

- Required fields validation
- ISBN validation
- Published year validation
- Duplicate book handling
- Server-side validation

### Dashboard

The dashboard displays:

- Total number of books
- Number of available books
- Number of issued books
